# HTML UI and Responsive Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every BulletsNdGuns screen (loader, menu, modals, HUD, game over, match in progress) out of Phaser into a React overlay styled "Pixel arcade", and make the 800x600 game scale to fit the window.

**Architecture:** One Zustand vanilla store (`ui/store.ts`) is the only bridge: Phaser scenes write screen/progress/HUD/result into it, React components read it with selectors and call its `ready()` action. A 4:3 `#stage` element sized by CSS holds Phaser's canvas (`Scale.FIT`) and the `#ui` overlay on top. UI sizes are expressed in 800x600 "game pixels" through a `--px` CSS variable built from container-query units, so the UI scales with the canvas.

**Tech Stack:** React 19.3, react-dom 19.3, Zustand 5, `radix-ui` 1.8 (Dialog), `@fontsource/press-start-2p` 5, `@vitejs/plugin-react` 6, `eslint-plugin-react-hooks` 7. Existing: Phaser 4.2, Vite 8, Vitest 5, TypeScript 6.0.3 (pinned).

**Spec:** `docs/superpowers/specs/2026-11-01-html-ui-design.md`. Read it first. The mockup for the look is `.superpowers/brainstorm/1307-1793566167/content/visual-style.html`, option B (git-ignored, local only; the spec's "Screens" section carries the values if it is missing).

## Global Constraints

- No gameplay change: physics, controls, timings, levels, sprites, sound effects and netcode stay as they are. No server changes.
- All player-facing text goes through `t()` in `packages/client/src/i18n`, Spanish only. Code, identifiers, comments and file names in English.
- Palette: navy `#14182b`, panel `#3a3f63`, purple `#7b3fbf`, brick `#8a3b2a` / `#b0533c`, yellow `#ffd23f`, white. Result colours: win `#00ff0d`, lose `#ff0000`, tie `#ffffff`.
- Boxes/buttons: square corners, 3px white border, 4px solid black drop shadow (all in game pixels, i.e. `calc(N * var(--px))`). Font: Press Start 2P, self-hosted.
- World stays 800x600. `pixelArt: true` stays. Canvas and UI sprites use `image-rendering: pixelated`.
- No Phaser text, images or pointer input for UI remains after Task 5.
- Use Zustand's vanilla store (`createStore` from `zustand/vanilla`) plus `useStore` in React. No Redux, no router, no TanStack Query.
- Use Radix Dialog for modals. Its portal must render into the `#ui` element (Radix `Dialog.Portal container`), not `document.body`, or the `--px` scaling breaks.
- Phaser 4 APIs only. Check `node_modules/phaser/skills/<topic>/SKILL.md` (e.g. `scale-and-responsive`, `loading-assets`) or `node_modules/phaser/types/phaser.d.ts` before touching Phaser code.
- TypeScript rules from `tsconfig.base.json` apply (`strict`, `erasableSyntaxOnly`, `verbatimModuleSyntax`, relative imports with `.ts`/`.tsx` extension).
- Work on branch `feat/html-ui`. Commit after every task with a conventional message ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `npm run lint`, `npm run typecheck`, `npm test` and `npm run build` pass at the end of every task.

## Review Focus

1. **Double-clicking COMENZAR** must send `ready` once. Test: Task 1 `ready() sends ready once and marks waiting`.
2. **HUD re-rendering every frame.** `LevelScene.render` runs every frame, so `setHud` with unchanged values must not notify subscribers. Test: Task 1 `setHud does not notify when values are unchanged`.
3. **A modal open when `levelStarted` arrives.** The menu unmounts. Radix must clean up its body `pointer-events: none` and scroll lock, and no element may keep focus, so `SPACE` reaches the game. Check: Task 6 browser step "dialog open at level start".
4. **Odd window shapes and live resize** (portrait, very wide, under 800x600, resizing mid-level): no scrollbars, HUD stays inside the game area, sprites stay crisp. Check: Task 6 browser step "sizes".
5. **Locale strings with markup** typed wrong (unknown or unclosed tag) must render as plain text, never as raw HTML. Test: Task 2 `keeps unknown or unclosed tags as plain text` and `every locale string parses cleanly`.

  ```ts
  export interface UiState {
    screen: Screen;
    matchInProgress: boolean;
    loading: { progress: number; file: string };   // progress 0..1
    hud: { ammo: number; coins: number };
    result: MatchResult | null;                    // MatchResult from @bng/shared
    waiting: boolean;                              // COMENZAR clicked
    setScreen(screen: Screen): void;
    setLoading(progress: number, file: string): void;
    setHud(ammo: number, coins: number): void;     // no-op (no notify) when unchanged
    setResult(result: MatchResult): void;          // also sets screen 'gameOver'
    showMatchInProgress(): void;
    ready(): void;                                 // first call: waiting=true + sendReady(); later calls no-op
  }
  export type UiStore = StoreApi<UiState>;         // StoreApi from 'zustand/vanilla'
  export interface UiActions { sendReady(): void }
  export function createUiStore(actions: UiActions): UiStore;
  ```
